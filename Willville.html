A Narrative 3D Adventure Slice

Willville is a low-poly narrative 3D vertical slice I built with Unity during a Synty GameJam a few months ago. This project utilizes minigames and NPC dialogues to advance a story about a small-town Mayor hoping to finish some last-minute tasks before a town celebration. Constructing this project required precise quest mapping, dialogue trees, and a volume of responsive NPC barks to bring the small town to life. Something I implemented for the first time with this project was Pixel Crushers Dialogue Manager, which was key in my ability to hold overlapping storylines together with a cohesive quest structure. The choice to make this project a WebGL build has also led me to learn a lot more about C# scripts, LODs refinement, and cross level loading.

✦ Design Highlights ✦
  • NPC Dialogue: Built responsive dialogue trees and barks directed at the player to make the town feel more aware of player's actions.
  • Minigame Designs: Created engaging short game loops that progress NPC stories and connect to the overarching quest line.
  • Quest Tracking/UI: Constructed UIs that update the player on each quest's progression level in both a journal format and corner screen tracker.

One of the key challenges in constructing Willville was planning the scope of a build that would stay playable in a WebGL format. As the side-by-side videos show, I was able to find a balance in things like the scene lighting and terrain that could still provide an enhanced atmosphere while keeping the settings within the necessary limitations. When I started crafting out the minigames and NPC interactions for Willville, it became clear that I needed to be mindful of the Dialogue Manager from PixelCrushers quest tracking, so each game was given its own game manager script to make sure that quests were progressing correctly and that the player's quest journal was accurately reporting this information to the player. Inside of the minigames, the movement and the physics of the objects needed to be measured for this system as well. Creating logic for the clouds in Cloud Chaser took some time to balance the fleeing from the player with the randomness they were promoted as having, but the more difficult experience for me was crafting the dart toss for the Dart Board challenge. Finding a way to show the dart traversing to the board without making the game unnecessarily difficult ultimately led to me creating a safe zone that would become the "called shot" system. In the end, I was able to improve this project by significantly expanding its main quest line, improving the carryover of data between scene loads, revamping the lighting, terrain, audio, and minigames as well as crafting a final cut scene.
